About this prerelease

6.0.0-alpha.1 is the first 6.x prerelease since 6.0.0-alpha.0 in June: 41 commits from <code>main</code>, 11 of them breaking. It's for trying 6.x in real apps and finding what breaks before 6.0.0-beta.0. APIs can still change until beta.

    npm install react-native-paper@alpha

Coming from 5.x or from alpha.0? Start with the [<a href="https://github.com/callstack/react-native-paper/blob/main/docs/6.x/docs/guides/migration.md">6.x migration guide</a>](<a href="https://github.com/callstack/react-native-paper/blob/main/docs/6.x/docs/guides/migration.md">https://github.com/callstack/react-native-paper/blob/main/docs/6.x/docs/guides/migration.md</a>). The breaking changes it doesn't cover yet are marked below. Please report problems as issues and mention 6.0.0-alpha.1.

Breaking changes since alpha.0

* <strong>Accessibility props</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4683924144" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5005" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5005/hovercard" href="https://github.com/callstack/react-native-paper/pull/5005">#5005</a>): <code>accessibilityLabel</code>, <code>accessibilityRole</code>, <code>accessibilityState</code> and related props become <code>aria-label</code>, <code>role</code>, <code>aria-disabled</code>, <code>aria-checked</code>, <code>aria-selected</code> and related props. The keys inside data objects change too: BottomNavigation <code>routes[]</code>, SegmentedButtons <code>buttons[]</code> and FAB.Menu items take <code>'aria-label'</code>. <em>Not in the migration guide yet.</em>
* <strong>Modal and Dialog render through their own Portal</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5468407589" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5126" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5126/hovercard" href="https://github.com/callstack/react-native-paper/pull/5126">#5126</a>): remove any <code>Portal</code> wrapper; a <code>PaperProvider</code> or <code>Portal.Host</code> must be above them, or they throw. While a modal is open, the app behind it is hidden from assistive technology and from test queries. <em>Partly in the migration guide.</em>
* <strong>Modal accessibility</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5467969957" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5125" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5125/hovercard" href="https://github.com/callstack/react-native-paper/pull/5125">#5125</a>): <code>overlayAccessibilityLabel</code> becomes <code>dismissAccessibilityLabel</code>; Modal and Dialog content have the dialog role and take <code>aria-label</code>; <code>dismissableBackButton</code> alone controls dismissal with the Android back button.
* <strong>Reanimated styles</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4762575542" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5015" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5015/hovercard" href="https://github.com/callstack/react-native-paper/pull/5015">#5015</a>): style props take styles from <code>useAnimatedStyle</code>; React Native <code>Animated</code> values are no longer accepted. <code>elevation</code> takes a level from 0 to 5 and animates changes itself. Appbar takes static styles and an <code>elevated</code> prop.
* <strong>Surface</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5257011777" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5078" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5078/hovercard" href="https://github.com/callstack/react-native-paper/pull/5078">#5078</a>): background color and corner radius move to the <code>backgroundColor</code>, <code>borderRadius</code> and <code>border*Radius</code> props; <code>overflow: hidden</code> and the <code>pointerEvents</code> prop are no longer supported. <code>style</code> no longer overrides the background or radius of Banner, Button, Card, Chip, Dialog, Menu <code>contentStyle</code>, Searchbar and Snackbar: use their color props or the theme.
* <strong>testIDs</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5309643008" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5088" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5088/hovercard" href="https://github.com/callstack/react-native-paper/pull/5088">#5088</a>, <a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5333867513" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5099" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5099/hovercard" href="https://github.com/callstack/react-native-paper/pull/5099">#5099</a>): components no longer set default testIDs or derive internal ones from yours. Pass <code>testID</code> explicitly; new props such as <code>iconTestID</code>, <code>trailingTestID</code> and <code>overlayTestID</code> replace the derived IDs.
* <strong>No more props injected into children</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5245617747" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5076" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5076/hovercard" href="https://github.com/callstack/react-native-paper/pull/5076">#5076</a>): Card pads its content itself; set <code>mode</code> and <code>compact</code> on each Button inside Card.Actions and Dialog.Actions; List.Accordion indents only List.Item children.
* <strong>Searchbar</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5423560678" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5117" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5117/hovercard" href="https://github.com/callstack/react-native-paper/pull/5117">#5117</a>): the <code>traileringIcon*</code> props are renamed to <code>trailingIcon</code>, <code>trailingIconColor</code>, <code>trailingIconAccessibilityLabel</code> and <code>onTrailingIconPress</code>.
* <strong>ToggleButton removed</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5325429174" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5095" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5095/hovercard" href="https://github.com/callstack/react-native-paper/pull/5095">#5095</a>): use IconButton with <code>selected</code>, or SegmentedButtons.
* <strong>Badge</strong> (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4725011116" data-permission-text="Title is private" data-url="https://github.com/callstack/react-native-paper/issues/5013" data-hovercard-type="pull_request" data-hovercard-url="/callstack/react-native-paper/pull/5013/hovercard" href="https://github.com/callstack/react-native-paper/pull/5013">#5013</a>): the <code>size</code> prop is removed; a Badge without children renders a 6dp dot, and with children a 16dp pill. <em>Not in the migration guide yet.</em>
