# v6.1.0-RC1

## release on 20261022
## description
## changes
⭐ New features

* Provide a <code>@JobParameter</code> annotation for more convenient access to variables in <code>JobParameters</code>. <a href="https://github.com/spring-projects/spring-batch/issues/5563" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5563/hovercard">#5563</a>
* Add <code>PageableItemReader</code> <a href="https://github.com/spring-projects/spring-batch/pull/5477" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5477/hovercard">#5477</a>
* Make <code>JsonLineMapper</code> agnostic to the JSON library <a href="https://github.com/spring-projects/spring-batch/pull/5345" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5345/hovercard">#5345</a>
* Introduce <code>JsonLineAggregator</code> for <code>FlatFileItemWriter</code> to write JSON Lines format file <a href="https://github.com/spring-projects/spring-batch/pull/5344" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5344/hovercard">#5344</a>
* Supports to create step execution with context <a href="https://github.com/spring-projects/spring-batch/pull/5184" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5184/hovercard">#5184</a>

🚀 Enhancements

* Introduce <code>RemoteChunkingManagerBuilder</code> and deprecate <code>RemoteChunkingManagerStepBuilder</code> and its factory <a href="https://github.com/spring-projects/spring-batch/issues/5598" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5598/hovercard">#5598</a>
* <code>JdbcJobExecutionDao.findJobExecutions</code> issues 1 + 3N queries for N executions <a href="https://github.com/spring-projects/spring-batch/issues/5570" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5570/hovercard">#5570</a>
* Polish <code>DatabaseType</code> <a href="https://github.com/spring-projects/spring-batch/pull/5542" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5542/hovercard">#5542</a>
* Improve <code>JdbcJobExecutionDao#synchronizeStatus(StepExecution)</code> <a href="https://github.com/spring-projects/spring-batch/pull/5365" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5365/hovercard">#5365</a>
* Refactor JDBC DAOs to use named parameters instead of positional parameters and <code>JdbcClient</code> instead of <code>JdbcTemplate</code> <a href="https://github.com/spring-projects/spring-batch/issues/4804" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/4804/hovercard">#4804</a>
* Eliminate unnecessary query for current version <a href="https://github.com/spring-projects/spring-batch/pull/4797" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/4797/hovercard">#4797</a>
* Poll workers of a partitioned step with a database query <a href="https://github.com/spring-projects/spring-batch/pull/4705" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/4705/hovercard">#4705</a>
* Running a job causes retrieval of full history of job executions <a href="https://github.com/spring-projects/spring-batch/issues/4169" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/4169/hovercard">#4169</a>
* Not unique steps names in a <code>FlowJob</code> should log a warning <a href="https://github.com/spring-projects/spring-batch/issues/3757" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/3757/hovercard">#3757</a>

🐞 Bug fixes

* Restart after a chunk scan that ended with a skipped item processes that item again <a href="https://github.com/spring-projects/spring-batch/issues/5599" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5599/hovercard">#5599</a>
* <code>ChunkOrientedStep</code> does not restore the step execution when a chunk transaction is not committed <a href="https://github.com/spring-projects/spring-batch/issues/5594" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5594/hovercard">#5594</a>
* <code>MongoCursorItemReader</code> throws <code>NullPointerException</code> when closed before opening <a href="https://github.com/spring-projects/spring-batch/issues/5589" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5589/hovercard">#5589</a>
* MariaDB 6.0 migration fails when renaming <code>BATCH_JOB_SEQ</code> <a href="https://github.com/spring-projects/spring-batch/issues/5586" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5586/hovercard">#5586</a>
* listener exceptions are skippable in scan mode but fatal elsewhere <a href="https://github.com/spring-projects/spring-batch/issues/5585" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5585/hovercard">#5585</a>
* Fix missing page increase in <code>AbstractPaginatedDataItemReader</code> <a href="https://github.com/spring-projects/spring-batch/pull/5583" data-hovercard-type="pull_request" data-hovercard-url="/spring-projects/spring-batch/pull/5583/hovercard">#5583</a>
* Job-scoped beans are not usable from worker threads of multi-threaded steps and parallel flows <a href="https://github.com/spring-projects/spring-batch/issues/5576" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5576/hovercard">#5576</a>
* <code>BatchObservabilityBeanPostProcessor</code> doesn't respect manually configured <code>observationRegistry</code> <a href="https://github.com/spring-projects/spring-batch/issues/5566" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5566/hovercard">#5566</a>
* Failed job launch leaves an orphan <code>JobInstance</code> behind <a href="https://github.com/spring-projects/spring-batch/issues/5562" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5562/hovercard">#5562</a>
* Restart after a failure during chunk scanning skips the remaining items of the chunk in <code>ChunkOrientedStep</code> <a href="https://github.com/spring-projects/spring-batch/issues/5558" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5558/hovercard">#5558</a>
* <code>NullPointerException</code> when closing an unopened <code>JpaPagingItemReader</code> <a href="https://github.com/spring-projects/spring-batch/issues/5539" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5539/hovercard">#5539</a>
* Misleading logs in scan mode without retries <a href="https://github.com/spring-projects/spring-batch/issues/5527" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5527/hovercard">#5527</a>
* <code>FlatFileItemReaderBuilder.addComment()</code> throws <code>UnsupportedOperationException</code> after <code>comments(...)</code> <a href="https://github.com/spring-projects/spring-batch/issues/5520" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5520/hovercard">#5520</a>
* <code>DelimitedLineTokenizer</code> throws <code>StringIndexOutOfBoundsException</code> when a field is a single quote character <a href="https://github.com/spring-projects/spring-batch/issues/5519" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5519/hovercard">#5519</a>
* <code>FixedLengthTokenizer</code> in strict mode rejects lines when the open-ended range starts at or before the first range's min <a href="https://github.com/spring-projects/spring-batch/issues/5518" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5518/hovercard">#5518</a>
* <code>JobFlowExecutor</code> leaks a <code>StepExecution</code> across job executions on a shared thread when no transition matches a step's <code>ExitStatus</code> <a href="https://github.com/spring-projects/spring-batch/issues/5514" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5514/hovercard">#5514</a>
* Aggregator of remote partitions is not passed all worker steps upon controller restart <a href="https://github.com/spring-projects/spring-batch/issues/5158" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-batch/issues/5158/hovercard">#5158</a>
