## release on 20260821
## description
## changes
:warning: Attention Required

* Spring Boot's Gradle plugin no longer automatically configures gRPC when the Protobuf plugin is applied. This behavior caused problems for those using Protobuf without gRPC. To opt in to the configuration of gRPC, configure the <code>protobuf</code> extension with the <code>grpc</code> plugin using an empty block. The Spring Boot Gradle plugin will then automatically configure the use of <code>protoc-gen-grpc-java</code> as before. <a href="https://github.com/spring-projects/spring-boot/issues/50822" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-boot/issues/50822/hovercard">#50822</a>
