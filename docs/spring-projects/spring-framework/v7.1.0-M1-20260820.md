## release on 20260820
## description
## changes
:warning: Attention Required

* starting in Spring Framework 7.1, <code>ForwardedHeaderFilter</code> (Spring MVC) and <code>ForwardedHeaderTransformer</code> (WebFlux) each require a boolean argument whether to use the standard "Forwarded" header or the "X-Forwarded" alternative headers. A separate property enables use of "X-Forwarded-Prefix" if needed. The default constructor with the existing behaviour of checking both types of headers is still available but deprecated and marked for removal. The new constructor makes forwarded header processing more deterministic and aligned with what is expected from the proxy. Please, see the updated <a href="https://docs.spring.io/spring-framework/reference/7.1-SNAPSHOT/web/webmvc/filters.html#filters-forwarded-headers-security" rel="nofollow">Security Considerations</a> section, as well as related changes in Spring Boot <a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4927745163" data-permission-text="Title is private" data-url="https://github.com/spring-projects/spring-boot/issues/51030" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-boot/issues/51030/hovercard" href="https://github.com/spring-projects/spring-boot/issues/51030">spring-projects/spring-boot#51030</a>. <a href="https://github.com/spring-projects/spring-framework/issues/37072" data-hovercard-type="issue" data-hovercard-url="/spring-projects/spring-framework/issues/37072/hovercard">#37072</a>
