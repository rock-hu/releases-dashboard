# SRU2026-9.7.1

## release on 20261007
## description
## changes
9.7.1 - October 2026

* (PW-3405) Feat: Configurable fallback zone for date time and time elements without offset (new adapter constructors and TypeAdaptersConfiguration.withFallbackZone); time elements now resolve the daylight-saving aware offset
* (PW-3251) Feat: lenient parsing of file-format (FileAct) payloads with sibling <code>AppHdr</code> and <code>Document</code> root elements or undeclared namespace prefixes, applied consistently across all parsing entry points without copying the payload (missing in 9.7.0)
* (PW-3251) <code>MxParseUtils.identifyMessage</code> now returns an empty Optional on blank input instead of throwing an IllegalArgumentException (missing in 9.7.0)
* (PW-3251) Added <code>MxParseUtils.needsNormalization</code> to check whether a payload needs lenient normalization without materializing the normalized content, for callers that only need the boolean outcome (e.g. file format detection)
* Fix: <code>MaxPrcgDt</code> (SRU2026 <code>JulianDate</code> type) in <code>Context26</code> and <code>Context27</code> is now mapped to <code>java.time.LocalDate</code> instead of <code>XMLGregorianCalendar</code>, consistent with the rest of the model; code using <code>getMaxPrcgDt()</code>/<code>setMaxPrcgDt()</code> must be adapted
* Updated Prowide Core dependency to SRU2026-9.7.1
