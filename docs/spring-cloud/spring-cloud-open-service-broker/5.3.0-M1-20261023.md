Spring Cloud Open Service Broker 5.3.0-M1

Spring Cloud Open Service Broker 5.3.0-M1 is the first milestone release in the 5.3.x line. Version 5.3.0-M1 is built against the Spring Boot 4.2 prerelease line (4.2.0-RC1) and requires Java 17+. The OSB API version is unchanged at v2.17, so this release adds no new OSB API support. It is intended for early testing against Spring Boot 4.2 and is not recommended for production use.

Highlights

* <strong>Built against Spring Boot 4.2 (4.2.0-RC1) and Spring Framework 7.1 (7.1.0-RC1)</strong>
* <strong>Fixed a duplicated <code>X-Broker-API-Request-Identity</code> response header</strong> on the Spring MVC (servlet) stack

Bug Fixes

* Fixed the <code>X-Broker-API-Request-Identity</code> response header being sent twice (for example <code>request-id, request-id</code>) on the Spring MVC stack. Broker controllers return reactive types, so Spring MVC handles each request asynchronously and dispatches it a second time through the same interceptors. <code>RequestIdentityInterceptor</code> added the header on both dispatches. It now sets the header, so the request identity is echoed exactly once, as the spec's <a href="https://github.com/openservicebrokerapi/servicebroker/blob/v2.17/spec.md#request-identity">Request Identity</a> section describes. The WebFlux stack was not affected.

Documentation

* Updated the README version compatibility section for the Spring Boot 4.2 prerelease line.

Build Improvements

* Upgraded to Gradle 9.8.2 (from 9.7.1).
* Migrated the WebMvc acceptance tests from <code>TestRestTemplate</code>, which is deprecated for removal in Spring Boot 4.2, to <code>RestTestClient</code>.

Dependency Upgrades

* Upgraded Spring Boot from 4.1.1 to 4.2.0-RC1.
* Upgraded <code>io.rest-assured:rest-assured</code> from 6.0.1 to 6.2.0.

Upgrade Notes

This is a milestone built on a Spring Boot release candidate, and it moves from Spring Boot 4.1 / Spring Framework 7.0 to Spring Boot 4.2 / Spring Framework 7.1. Applications that need to stay on Spring Boot 4.1 should remain on 5.2.x.

The public API of this library is unchanged from 5.2.0, and the OSB API version remains v2.17. The one observable behavior change is on the Spring MVC stack: the <code>X-Broker-API-Request-Identity</code> response header now appears once instead of twice. This only matters to clients that read every value of the header, since a client that reads the first value is unaffected.
