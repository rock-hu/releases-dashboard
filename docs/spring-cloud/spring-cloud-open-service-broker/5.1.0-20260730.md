## release on 20260730

## changes
Spring Cloud Open Service Broker 5.1.0

Spring Cloud Open Service Broker 5.1.0 is now GA. Version 5.1.0 is built against Spring Boot 4.1 and requires Java 17+. It includes continued support for OSB API v2.16. This release upgrades core dependencies, replaces third-party utility libraries with Spring equivalents, and modernizes the Gradle build infrastructure.

Versions

| Component | Version |
|------------------|---------|
| Spring Boot | 4.1.0 |
| Spring Framework | 7.0.8 |
| Java | 17+ |
| OSB API | 2.16 |

Highlights

* <strong>Spring Boot 4.1.0</strong> (upgraded from Spring Boot 4.0.x)
* <strong>Gradle 9.6.1</strong> build infrastructure (upgraded from Gradle 9.4.x)
* Replaced third-party <code>commons-beanutils</code> and <code>commons-collections</code> with Spring equivalents
* Bug fix for null safety in <code>ServiceInstanceBindingController</code> operation equality check
* CI now builds and tests the 5.1.x branch, with Dependabot enabled and the unsupported 4.5.x branch retired

Dependency Improvements

Remove Apache Commons Dependencies

* Replaced usage of <code>commons-collections</code> with Spring's <code>CollectionUtils</code> in <code>EventFlowRegistry</code>, eliminating the transitive dependency.
* Replaced usage of <code>commons-beanutils</code> with Spring's <code>BeanWrapper</code> in <code>ParameterBeanMapperUtils</code>, eliminating the transitive dependency.

Build Dependency Cleanup

* Use the Spring Boot managed version of Hamcrest rather than a manually pinned version.
* Removed the Wiremock Gradle constraint, previously required for a Logback classpath conflict resolved by the Spring Cloud Contract upgrade.
* Reduced scope of the <code>findbugs</code> dependency from <code>testImplementation</code> to <code>testCompileOnly</code>.
* Pinned <code>spring-mock-mvc</code> to support Groovy 5, then extracted the <code>rest-assured</code> version to a Gradle property and bumped <code>rest-assured:spring-mock-mvc</code> from 6.0.0 to 6.0.1.
* Bumped <code>spring-cloud-contract</code> from 5.0.2 to 5.0.3 and <code>blockhound-junit-platform</code> from 1.0.16 to 1.0.17.

Bug Fixes

* Fixed a null pointer risk in the operation equality check in <code>ServiceInstanceBindingController</code>, making the logic consistent with the equivalent check in <code>ServiceInstanceController</code>.

Improvements

* Simplified the service binding last operation response mapping in <code>ServiceInstanceBindingController</code>.

Build Improvements

* Upgraded Gradle from 9.4.0 through 9.6.1 over the course of the release.
* Removed deprecated Gradle APIs: <code>getProperties</code>, implicit parent property lookup, and the <code>optionalApi</code> feature variant.
* Removed unnecessary Gradle <code>eclipse</code>/<code>idea</code> plugins and old Java version guards for Java 11/13.
* Fixed eager task configuration by using the modern Gradle <code>configureEach</code> block.
* Suppressed a spurious JDK IO subsystem warning from AsciidoctorJ's JRuby engine during the docs build.
* Added support for retrieving build dependencies from an alternative artifactory.
* Enabled Dependabot and CI pipelines for the 5.1.x branch; fixed the documentation workflow (javadoc JAR generation, apidocs path, shell issues).
* Removed the unsupported 4.5.x branch from CI pipelines and Dependabot configuration.
* Updated the README version compatibility matrix.

Upgrade Notes

The <code>spring-cloud-open-service-broker-webmvc</code> and <code>spring-cloud-open-service-broker-webflux</code> dependencies are no longer marked as optional in the published Maven POMs. Consumers that relied on this hint to see the dependency suggested transitively will no longer see it listed; this has no functional effect, and projects must continue to explicitly declare a Spring MVC or Spring WebFlux dependency as before.
