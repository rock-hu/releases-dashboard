Spring Cloud Open Service Broker 5.0.2

Spring Cloud Open Service Broker 5.0.2 is a patch release in the 5.0.x line. Version 5.0.2 is built against Spring Boot 4.0 and requires Java 17+. It includes support for OSB API v2.16. This release picks up Spring Boot 4.0.9 and brings the build infrastructure in line with the 5.1.x line. There are no functional changes to the library.

Versions

| Component | Version |
|------------------|---------|
| Spring Boot | 4.0.9 |
| Spring Framework | 7.0.10 |
| Java | 17+ |
| OSB API | 2.16 |

Highlights

* <strong>Spring Boot 4.0.9</strong> (upgraded from Spring Boot 4.0.7)
* <strong>Gradle 9.8.2</strong> build infrastructure (upgraded from Gradle 9.5.1), with plugin and dependency versions moved to a Gradle version catalog
* The published Maven POMs no longer declare the Spring web dependencies as optional (no functional change)
* Fixed the reference documentation table-of-contents sidebar

Documentation

* Modernized the documentation build to match the 5.1.x line, and fixed a broken table-of-contents sidebar in the reference docs.

Build Improvements

* Upgraded Gradle from 9.5.1 to 9.8.2.
* Migrated plugin and dependency versions to a Gradle version catalog, which also removes deprecation warnings about implicit property lookup in parent projects.
* Ported the Gradle build fixes from 5.1.x and added Artifactory-backed build support, matching 5.1.x.
* Replaced the deprecated <code>optionalApi</code> Gradle feature variant with standard <code>compileOnly</code> dependencies.
* Upgraded Spring Java Format to 0.0.48, which changes some nested-class references (such as <code>JsonInclude.Include.NON_NULL</code>) to imports. This is a source-style change only and does not affect behavior.
* Fixed the stage job failing to resolve Gradle plugins.

Dependency Upgrades

* Bumped Spring Boot from 4.0.7 to 4.0.9.
* Bumped <code>io.rest-assured:rest-assured</code> from 6.0.0 to 6.2.0.
* Bumped <code>nl.jqno.equalsverifier:equalsverifier</code> from 4.5 to 4.5.2.

Upgrade Notes

This is a drop-in upgrade from 5.0.1: the public API of this library and the OSB API version (v2.16) are unchanged.

The published Maven POMs for <code>spring-cloud-open-service-broker-core</code> and <code>spring-cloud-open-service-broker-autoconfigure</code> no longer list <code>spring-webmvc</code>, <code>spring-webflux</code> and the matching Spring Boot starters as optional dependencies. They were only a hint that an application should bring one of them, and optional dependencies were never transitive, so dependency resolution is unchanged. As before, your application is expected to include Spring MVC or Spring WebFlux itself. The 5.1.x and 5.2.x lines already published their POMs this way.
