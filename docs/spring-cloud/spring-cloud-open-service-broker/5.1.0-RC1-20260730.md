Spring Cloud Open Service Broker 5.1.0-RC1

Spring Cloud Open Service Broker 5.1.0-RC1 is the release candidate for the upcoming 5.1.0 GA release. This release includes a minor test dependency update and build maintenance, with no functional changes since 5.1.0-M2.

Versions

| Component | Version |
|------------------|---------|
| Spring Boot | 4.1.0 |
| Spring Framework | 7.0.8 |
| Java | 17+ |
| OSB API | 2.16 |

Highlights

* Updated the README version compatibility matrix to include the 5.1.x line.

Build Improvements

* Bumped <code>rest-assured:spring-mock-mvc</code> from 6.0.0 to 6.0.1.
* Extracted the <code>rest-assured</code> version to a Gradle property.
* Removed the unsupported 4.5.x branch from CI pipelines and Dependabot configuration.
