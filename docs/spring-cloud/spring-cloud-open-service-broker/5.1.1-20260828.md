Spring Cloud Open Service Broker 5.1.1

Spring Cloud Open Service Broker 5.1.1 is now GA. Version 5.1.1 is built against Spring Boot 4.1 and requires Java 17+. It includes continued support for OSB API v2.16. This release closes several OSB API v2.16 compliance gaps, fixes incorrect HTTP status codes returned when polling a missing resource's last operation, and continues modernizing the Gradle build infrastructure.

| Component | Version |

Highlights

* Closed three OSB API v2.16 field gaps: <code>app_annotations</code> and <code>credential_client_id</code> on <code>BindResource</code>, and <code>instance_annotations</code> on <code>CloudFoundryContext</code>
* Fixed the <code>X-Broker-API-Request-Identity</code> response header not being echoed back on Spring MVC brokers
* Polling <code>last_operation</code> for a missing service instance or service binding now correctly returns <code>404 Not Found</code> instead of <code>400</code>/<code>422</code>
* <strong>Gradle 9.7.1</strong> build infrastructure (upgraded from Gradle 9.6.1)
* Documented <code>@since</code> OSB API version tags across the core javadoc

OSB API Compliance

* Added <code>app_annotations</code> to <code>BindResource</code>, part of the OSB API v2.16 Cloud Foundry Bind Resource object.
* Added <code>credential_client_id</code> to <code>BindResource</code>, the optional Cloud Foundry Bind Resource property carrying the CredHub client id for a service key request.
* Added <code>instance_annotations</code> to <code>CloudFoundryContext</code>, part of the OSB API v2.16 Cloud Foundry Context object.
* Registered <code>RequestIdentityWebMvcConfigurerAdapter</code> so the existing <code>RequestIdentityInterceptor</code> bean is actually applied to Spring MVC brokers. The interceptor implemented the spec's <code>X-Broker-API-Request-Identity</code> echo requirement but was never added to the <code>InterceptorRegistry</code>, so it had no effect; WebFlux brokers were unaffected since <code>RequestIdentityWebFilter</code> applies globally regardless of registration. Added end-to-end tests in both the webmvc and webflux acceptance modules that exercise the header through a real running application.
* Documented which OSB API spec version introduced each field, method, and endpoint across the model, exception, controller, and service classes, and pointed spec links at the v2.16 tag instead of <code>master</code> so they don't drift as the spec evolves.

Bug Fixes

* Polling <code>last_operation</code> for a missing service instance now returns <code>404 Not Found</code> instead of <code>400 Bad Request</code>, matching the OSB API v2.16 spec.
* Polling <code>last_operation</code> for a missing service binding now returns <code>404 Not Found</code> instead of <code>422</code>; <code>ServiceInstanceBindingController</code> previously had no exception handling here at all, so the failure fell through to the generic handler's <code>422</code> mapping.
* Added unit test coverage for the remaining <code>ServiceInstanceBindingController</code> <code>last_operation</code> status branches (in progress, succeeded, succeeded-with-delete, failed), matching the existing coverage for service instances.
