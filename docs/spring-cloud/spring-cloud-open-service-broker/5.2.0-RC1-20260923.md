Spring Cloud Open Service Broker 5.2.0-RC1

Spring Cloud Open Service Broker 5.2.0-RC1 is the release candidate for the upcoming 5.2.0 GA release. Version 5.2.0-RC1 is built against Spring Boot 4.1 and requires Java 17+. It continues support for OSB API v2.17 and adds optional <code>Retry-After</code> header support for <code>last_operation</code> polling responses. This is an additive change with no breaking changes since 5.2.0-M1.

Highlights

* <strong><code>Retry-After</code> header support</strong> for <code>last_operation</code> polling responses, per OSB API v2.15 guidance
* No breaking changes since 5.2.0-M1

OSB API Compliance

* Added an optional <code>retryAfter</code> field to <code>GetLastServiceOperationResponse</code> and <code>GetLastServiceBindingOperationResponse</code>. When a service broker implementation sets it, the value is applied as the <code>Retry-After</code> HTTP header on the corresponding <code>GET .../last_operation</code> response, per the OSB API 2.15 "Polling Last Operation" guidance that the header MAY be included and is RECOMMENDED to be a duration rather than a timestamp. The field is not part of the JSON response body.

Upgrade Notes

This release is fully additive: <code>retryAfter</code> is a new optional field with no effect unless a broker implementation sets it, and existing constructors on both response classes are preserved (deprecated, not removed) so no existing caller's source or binary compatibility is affected. Service brokers built against 5.2.0-M1 or earlier are unaffected and require no changes to keep working.
