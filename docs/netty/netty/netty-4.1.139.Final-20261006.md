Note that due to overwhelming strain on the CVE infrastructure, we have not gotten a single CVE number assigned to these reports in time for our release.  

The advisories will be published without.

Specific changes worth calling out:

<strong>Validation in <code>FileUpload.setContentType</code>.</strong>  

Previously, the <code>FileUpload.setContentType</code> methods did not validate their inputs.  

They now throw an <code>IllegaalArgumentException</code> if the given string is not formatted as a plausible MIME content type.
