## changes
:warning: Noteworthy

* <strong>Atlas FunctionTimer behavior change</strong>: <code>AtlasMeterRegistry</code> now publishes <code>FunctionTimer</code> statistics (<code>count</code> and <code>totalTime</code>) as per-second rates instead of gauges (<a href="https://github.com/micrometer-metrics/micrometer/pull/8108" data-hovercard-type="pull_request" data-hovercard-url="/micrometer-metrics/micrometer/pull/8108/hovercard">#8108</a>). With the default 1-minute step, published values will be ~60x lower than before; any dashboard queries or alert rules dividing by 60 should be updated. See the <a href="https://github.com/micrometer-metrics/micrometer/wiki/1.18-Migration-Guide#atlas-functiontimer-statistics-published-as-rates">1.18 Migration Guide</a> for details.
