# v0.27.63: Store routes compressed-only, decompress on demand (#4198)

## release on 20260819
## description
## changes
With the introduction of the zone aware routing memory consumption  

increased x4 - instead of one uncompressed routeTree + compressed  

buffer, we additionally store same routetree for every az - the route  

data is the same, only engpoints are changing.

An easy win is - not store the uncompressed buffed and decomress it on  

demand. Majority of the clients use compression, so the change will not  

affect cpu drasticlally.

Included benchmark shows small difference in allocations and timings
