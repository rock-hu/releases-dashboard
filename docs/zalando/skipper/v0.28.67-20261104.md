Summary

Ensures <code>RouteGroup</code> sub-component validation errors (filters,  

predicates, backends, and duplicate hosts) include the target resource's  

namespace and name (<code>error in route group &lt;namespace&gt;/&lt;name&gt;: &lt;err&gt;</code>),  

resolving prior TODOs and standardizing error reporting across the  

Kubernetes dataclient and admission controller.

Motivation

Validation failures in sub-components previously returned unwrapped  

error strings (such as <code>parse failed after token ...</code> or <code>backend address ... does not match scheme://host format</code>). In admission logs and  

cluster-wide validation pipelines, this lacked resource context, making  

it difficult to pinpoint which <code>RouteGroup</code> triggered the failure.
