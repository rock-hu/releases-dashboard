New optional filters interface, if implemented filter will be redacted by listing return values from <code>filter.RedactedArgs()</code> instead of local filter args:

    type Redactable interface {
    	// RedactedArgs returns a copy of the original creation args with sensitive
    	// values replaced by a placeholder. Must not modify the original args slice.
    	RedactedArgs() []any
    }
