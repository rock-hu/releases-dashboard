Problem

<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5247859063" data-permission-text="Title is private" data-url="https://github.com/zalando/skipper/issues/4223" data-hovercard-type="pull_request" data-hovercard-url="/zalando/skipper/pull/4223/hovercard" href="https://github.com/zalando/skipper/pull/4223">#4223</a> added a parse cache scoped to a single <code>RouteGroup</code>, so a filter  

or predicate string repeated across the routes of one RouteGroup is  

parsed once. In a real cluster many RouteGroups repeat the same strings  

(<code>Method("GET")</code> appears in almost every one), and those are still  

parsed once per RouteGroup.

Change

<code>RouteGroupList.ShareParseCache()</code> gives every RouteGroup in a load one  

shared filter map and one shared predicate map. It is called in  

<code>clusterClient.LoadRouteGroups</code> right after the RouteGroups are fetched,  

before validation and conversion. Both phases already go through  

<code>RouteGroupSpec.ParseFilter</code> / <code>ParsePredicate</code>, so a string that  

repeats across RouteGroups is now parsed once per load instead of once  

per RouteGroup. <code>ParseFilter</code> / <code>ParsePredicate</code> are unchanged.

Correctness

The parsed <code>*eskip.Filter</code> / <code>*eskip.Predicate</code> were already shared  

across the routes of a RouteGroup by <a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5247859063" data-permission-text="Title is private" data-url="https://github.com/zalando/skipper/issues/4223" data-hovercard-type="pull_request" data-hovercard-url="/zalando/skipper/pull/4223/hovercard" href="https://github.com/zalando/skipper/pull/4223">#4223</a> and documented as "MUST NOT  

be mutated in place". Sharing them across RouteGroups keeps the same  

contract: conversion only appends them to route slices  

(<code>transformExplicitGroupRoute</code>), and eskip deep-copies routes  

(<code>Route.Copy</code>, which copies filters and predicates) before any mutation.  

Validation and conversion run from a single goroutine over the load,  

matching the previous per-RouteGroup cache, so no locking is added. <code>go test -race ./dataclients/kubernetes/...</code> passes.

Benchmark

<code>BenchmarkRouteGroupsLoadAll</code> already loads 200 RouteGroups that repeat  

the same filter and predicate strings, so it exercises the  

cross-RouteGroup case directly. <code>benchstat</code> over 10 runs, per-RouteGroup  

cache (base) vs shared cache:
