Description

Implements support for the HTTP <code>QUERY</code> method as specified in <a href="https://www.rfc-editor.org/rfc/rfc10008" rel="nofollow">RFC<br>
10008</a>. Because Go's <code>net/http</code>  

standard library does not yet export <code>MethodQuery</code>, we define  

<code>MethodQuery = "QUERY"</code> locally where necessary.

Key changes:

1. <strong><code>predicates/methods</code></strong>: Added <code>MethodQuery</code> constant and enabled  
   predicate matching for <code>QUERY</code> requests (including case-insensitive  
   handling).
2. <strong><code>metrics</code></strong>: Added <code>QUERY</code> to <code>measuredMethod</code> so requests using  
   <code>QUERY</code> are properly labeled rather than falling back to  
   <code>_unknownmethod_</code>. Added unit test coverage in <code>metrics/utils_test.go</code>.
3. <strong><code>filters/apiusagemonitoring</code></strong>: Added <code>methodIndexQuery</code> enum and  
   mapped <code>"QUERY"</code> in <code>methodToIndex</code>. Updated method test suite to verify  
   endpoint metrics tracking for <code>QUERY</code>.
4. <strong><code>docs/reference/predicates.md</code></strong>: Updated documentation and  
   examples for <code>Method</code> and <code>Methods</code> predicates to include <code>QUERY</code>.

Tests
