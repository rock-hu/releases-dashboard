Increases unit test statement coverage for <code>filters/log</code> from 27.0% to  

96.6%.

Changes

* <strong>auditLog Filter Spec</strong>:
  * Test <code>NewAuditLog()</code> constructor and <code>Name()</code>.
* Test <code>CreateFilter()</code> parameter validation and error handling on  
  unexpected arguments.
* <strong>teeBody</strong>:
  * Test <code>newTeeBody()</code>, <code>Read()</code>, <code>Close()</code>, and <code>Write()</code>.
* Cover bounded truncation (<code>maxTee &gt; 0</code>) vs. unbounded capture (<code>maxTee &lt; 0</code>).
* <strong>auditLog Filter Execution</strong>:
* Test <code>Request()</code> body wrapping when <code>maxBodyLog != 0</code> vs. unchanged  
  when <code>0</code>.
* Test <code>Response()</code> JSON serialization for method, path, status code,  
  and request body.
* Test <code>StateBag</code> extraction for <code>AuthUserKey</code> and  
  <code>AuthRejectReasonKey</code>.
* <strong>unverifiedAuditLog Spec</strong>:
* Test <code>NewUnverifiedAuditLog()</code>, <code>Name()</code>, and invalid parameter  
  validation in <code>CreateFilter()</code>.
