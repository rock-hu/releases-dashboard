valkey: make operation SetWithExpire atomic (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5269452653" data-permission-text="Title is private" data-url="https://github.com/zalando/skipper/issues/4226" data-hovercard-type="pull_request" data-hovercard-url="/zalando/skipper/pull/4226/hovercard" href="https://github.com/zalando/skipper/pull/4226">#4226</a>)

<code>SetWithExpire</code> previously sent separate <code>SET</code> and <code>EXPIRE</code> commands,  

which were not atomic and could leave a key without a TTL. It now uses a  

single <code>SET ... PX &lt;milliseconds&gt;</code> command.
