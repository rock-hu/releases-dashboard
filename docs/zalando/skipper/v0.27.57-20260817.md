Enabling h2c for client to skipper requires skipper server handler to be configured by <code>-enable-h2c-server</code>.  

Enabling h2c from skipper to backend is done automatically by choosing <code>h2c://</code> as scheme. In kubernetes this can be achieved, if you have enabled <code>-enable-kubernetes-endpointslices</code>, and choose the appProtocol on your Kubernetes service, examples:

eskip

    h2c: * -> "h2c://127.0.0.1:9000";
    h2c_lb: * -> <roundRobin, "h2c://127.0.0.1:9000", "h2c://127.0.0.1:9001">;

kubernetes

    apiVersion: v1
    kind: Service
    metadata:
      name: app-svc
    spec:
      ports:
      - port: 80
        appProtocol: kubernetes.io/h2c
