# 4.2.0

## release on 20260918
## description
## changes
<a href="https://github.com/zalando/logbook/compare/4.1.0...4.2.0">Full Changelog</a>

<strong>Breaking changes:</strong>

* <code>FastJsonHttpLogFormatter(JsonFactory, JsonFieldWriter, boolean)</code> was removed while preserving the configured mapper's <code>ObjectWriteContext</code>. Use <code>FastJsonHttpLogFormatter(JsonFactory, JsonFieldWriter)</code> or <code>FastJsonHttpLogFormatter(JsonMapper, JsonFieldWriter)</code> instead. <a href="https://github.com/zalando/logbook/pull/2390" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2390/hovercard">#2390</a>

<strong>Highlights:</strong>

* Add independent <code>logbook.server.predicate.*</code> and <code>logbook.client.predicate.*</code> configuration for incoming and outgoing requests. Existing global <code>logbook.predicate.*</code> rules still apply to both. <a href="https://github.com/zalando/logbook/pull/2401" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2401/hovercard">#2401</a>
* Add <code>logbook.reactive.server-mode=web-filter</code> for Spring WebFlux server logging within the WebFlux pipeline and trace-context correlation. The default <code>netty</code> mode remains unchanged. <a href="https://github.com/zalando/logbook/pull/2380" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2380/hovercard">#2380</a>
* Add <code>AsyncOnCompleteListenerWrapper</code> for restoring thread-local context while logging servlet async responses. The Spring Boot starter applies an <code>AsyncOnCompleteListenerWrapper</code> bean to both Logbook filters. <a href="https://github.com/zalando/logbook/pull/2345" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2345/hovercard">#2345</a>
* ECS logging now skips body processing when TRACE is disabled and honors <code>logbook.write.status-code-based</code> for response log levels. <a href="https://github.com/zalando/logbook/pull/2388" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2388/hovercard">#2388</a> <a href="https://github.com/zalando/logbook/pull/2379" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2379/hovercard">#2379</a>

<strong>Compatibility notes:</strong>

* <code>EcsSink</code> and <code>StatusCodeBasedSink</code> are deprecated. Spring Boot auto-configuration now creates their replacements; applications autowiring either concrete type should inject <code>Sink</code> instead. <a href="https://github.com/zalando/logbook/pull/2379" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2379/hovercard">#2379</a>

<strong>Fixed bugs:</strong>

* Prevent WebFlux response replay from re-subscribing to one-shot response bodies. <a href="https://github.com/zalando/logbook/pull/2373" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2373/hovercard">#2373</a>
* Fix logging of HttpClient 5 asynchronous chunked request bodies with an unknown content length. <a href="https://github.com/zalando/logbook/pull/2360" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2360/hovercard">#2360</a>
* Ignore missing JSONPath targets when replacing or deleting body fields instead of logging <code>ClassCastException</code>. <a href="https://github.com/zalando/logbook/pull/2361" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2361/hovercard">#2361</a>

<strong>Dependency updates:</strong>

* Update managed dependencies, including Spring Boot 4.1.1, Spring Framework 7.0.9, Jackson 2.22.2 and 3.2.2, and HttpClient 5.6.4. <a href="https://github.com/zalando/logbook/pull/2397" data-hovercard-type="pull_request" data-hovercard-url="/zalando/logbook/pull/2397/hovercard">#2397</a>
