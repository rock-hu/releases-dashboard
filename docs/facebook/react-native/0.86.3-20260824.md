# 0.86.3

## release on 20260824
## description
## changes
* <strong>Hermes:</strong> Bump hermes-v1 to 250829098.0.17 (<a href="https://github.com/react/react-native/commit/3fd71f07c389c9310630b418c270b742fbb4e948">3fd71f07c3</a> by <a href="https://github.com/cipolleschi">@cipolleschi</a>)
* <strong>EventEmitter:</strong> Fix use-after-free data race in EventEmitter.cpp (<a href="https://github.com/react/react-native/commit/fdb26edfe79041380147b0dde0ccd6552d29d31b">fdb26edfe7</a>)
* <strong>Modal:</strong> Fix <code>parentNode</code>/<code>parentElement</code> returning the document instead of the containing element for <code>&lt;Modal&gt;</code> and other nested root host views, which severed capture/bubble event propagation to ancestors rendered above them (<a href="https://github.com/react/react-native/commit/6e3f0e8f9fbb947fc05d7f91a625705d599a3144">6e3f0e8f9f</a> by <a href="https://github.com/rubennorte">rubennorte</a>)
* <strong>Cocoapods:</strong> Make Podfile.lock SPEC CHECKSUMS deterministic across machines by sorting Dir.glob results in Yoga.podspec and using a dynamically computed Pods-relative path in hermes-engine.podspec (<a href="https://github.com/react/react-native/commit/6e3f0e8f9fbb947fc05d7f91a625705d599a3144">6e3f0e8f9f</a> by <a href="https://github.com/IsaacIsrael">IsaacIsrael</a>)
* <strong>Runtime:</strong> Fix ConcurrentModificationException when getInitialURL re-enters during onHostResume (<a href="https://github.com/react/react-native/commit/20d04aefa17acbbbf89ff055adf798827bd7787b">20d04aefa1</a> by <a href="https://github.com/nickcernera">@nickcernera</a>)
* <strong>Font:</strong> Custom fonts with an explicit fontWeight no longer render at the heaviest weight on the New Architecture (<a href="https://github.com/react/react-native/commit/918fb15bfe5ff434d036c91be957de62cf8f8449">918fb15bfe</a> by <a href="https://github.com/jensdev">@jensdev</a>)
