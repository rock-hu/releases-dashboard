# 0.88.0-rc.3

## release on 20260928
## description
## changes
Changed

* <strong>Hermes</strong>: Bump to <code>260318099.0.4</code>, which avoids a quadratic <code>reserve()</code> in <code>ConsecutiveStringStorage</code> during lazy compilation (<a href="https://github.com/react/react-native/commit/993be7d6c69c838bd6fb7acf6b979f8ea65ca03c">993be7d6c6</a> by <a href="https://github.com/fabriziocucci">@fabriziocucci</a>)

Fixed

* <strong>Metro</strong>: Fix the package-exports warning caused by <code>react-native/virtualized-lists</code> importing an unexported React Native subpath (<a href="https://github.com/react/react-native/commit/a506ed66cc5744ec017556f49a2c296fb4bad318">a506ed66cc</a> by <a href="https://github.com/giaBaoJS">@giaBaoJS</a>)

Android specific

* <strong>SurfaceMountingManager</strong>: Bump <code>androidx.collection</code> to 1.4.4 to fix view registry entries getting lost (<a href="https://github.com/react/react-native/commit/d6a5f159c6ef81651d38af2a33338b921700e044">d6a5f159c6</a> by <a href="https://github.com/pawicao">@pawicao</a>)

iOS specific

* <strong>SwiftPM</strong>: Stop autolinking from recreating library package roots on every sync, which broke Xcode builds of apps using libraries that ship their own <code>Package.swift</code> (<a href="https://github.com/react/react-native/commit/97cc934dc75184977363e06b1793277de82fed54">97cc934dc7</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
