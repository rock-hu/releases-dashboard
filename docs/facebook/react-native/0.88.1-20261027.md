# 0.88.1

## release on 20261027
## description
## changes
Added

* <strong>JSI:</strong> Forward createValueFromJsonUtf8 in RuntimeDecorator (<a href="https://github.com/react/react-native/commit/b5eec4e4f3d76fe0f407a5666d0ffdb5eb218b57">b5eec4e4f3</a> by <a href="https://github.com/mrousavy">@mrousavy</a>)
* <strong>JSI:</strong> Run the With hooks around WithRuntimeDecorator::createArrayBuffer (<a href="https://github.com/react/react-native/commit/82def6ea4c67b5b803da2c777d8eff16919d0a23">82def6ea4c</a> by <a href="https://github.com/mrousavy">@mrousavy</a>)
* <strong>JSI:</strong> Forward String::length in RuntimeDecorator and WithRuntimeDecorator (<a href="https://github.com/react/react-native/commit/be567d270ca860a57bc30449f9a34df5b751059c">be567d270c</a> by <a href="https://github.com/mrousavy">@mrousavy</a>)
* <strong>Yoga:</strong> Fix flex shrink explosion when the shrink total is a positive float residual (<a href="https://github.com/react/react-native/commit/24a3be5f99be002fc5b19b05647cb241a7435df1">24a3be5f99</a> by <a href="https://github.com/intergalacticspacehighway">@intergalacticspacehighway</a>)

iOS specific

* <strong>SwiftPM:</strong> the build stops with a clear error when precompiled plugin frameworks and the Xcode project disagree, and the error says what to run. (<a href="https://github.com/react/react-native/commit/a920e5db46876daa4defc3a75fbb11f636c1f0ce">a920e5db46</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)

Changed

* <strong>JSI:</strong> Use createError in JSError and forward it in RuntimeDecorator (<a href="https://github.com/react/react-native/commit/0cca3a1f77216f815854769659dcba9965d3b12e">0cca3a1f77</a> by <a href="https://github.com/mrousavy">@mrousavy</a>)

iOS specific

* <strong>Build:</strong> Compile React Native's C/C++/Objective-C code with <code>-O2</code> instead of <code>-Os</code> in Release, and Yoga and glog with <code>-O2</code> in all builds, to match Android (<a href="https://github.com/react/react-native/commit/60c817e9256abaea212ebd826d18043d4f1c5109">60c817e925</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>SwiftPM:</strong> <code>spm add</code> and <code>spm update</code> write React Native's build settings to <code>ReactNativeSPM/ReactNativeSPM.xcconfig</code> and its build scripts to <code>ReactNativeSPM/Scripts/</code>, so a version bump no longer changes <code>project.pbxproj</code>. A configuration that uses its own xcconfig must now <code>#include</code> the generated file, and a target setting that hides React Native's value must add <code>$(inherited)</code>. <code>spm</code> prints the exact fix in both cases. (<a href="https://github.com/react/react-native/commit/cd89e98949d1471c801a2ee40be676f73bceeec2">cd89e98949</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>Text:</strong> Text without a background color no longer draws a transparent background (<a href="https://github.com/react/react-native/commit/0bd33261d1e519f319c3225247879273c5a2a709">0bd33261d1</a> by <a href="https://github.com/hryhoriiK97">@hryhoriiK97</a>)

Fixed

* <strong>LogBox</strong>: Fix bottom notification appearance/touch targets on iPhone Duo (<a href="https://github.com/react/react-native/commit/88a8bd23e8744b1cdc5618f7c985eafbb835ff93">88a8bd23e8</a> by <a href="https://github.com/huntie">@huntie</a>)
* <strong>Yoga:</strong> Keep the measured pixel size of text nodes when rounding to the pixel grid (<a href="https://github.com/react/react-native/commit/fd5392494fc547e049c933203953aeedd437175d">fd5392494f</a> by <a href="https://github.com/intergalacticspacehighway">@intergalacticspacehighway</a>)

Android specific

* <strong>Text:</strong> Fix text measured with the wrong width when <code>fontVariationSettings</code> are re-applied to a reused <code>Paint</code> (<a href="https://github.com/react/react-native/commit/96518a8fb9b380422ff428e44e7602977a8ec1dd">96518a8fb9</a> by <a href="https://github.com/jkadamczyk">@jkadamczyk</a>)
* <strong>Text:</strong> Skip empty and fully hidden text decoration ranges (<a href="https://github.com/react/react-native/commit/dbd5b3b770039b86cf8c538cb52eb860717d0e88">dbd5b3b770</a> by <a href="https://github.com/Abbondanzo">@Abbondanzo</a>)
* <strong>Text:</strong> Fix crash drawing text decoration (underline/strikethrough) when a nested Text's span extends past a numberOfLines-truncated layout (<a href="https://github.com/react/react-native/commit/ca8504b1caa9f79152cc14fcc6c0d7e46ada2633">ca8504b1ca</a> by <a href="https://github.com/lazerg">@lazerg</a>)

iOS specific

* <strong>Image:</strong> Image no longer shows the image of a previous source after its native view is recycled (<a href="https://github.com/react/react-native/commit/53bf98bf40713fad1bbe00a652d2aabce8b91eb1">53bf98bf40</a> by <a href="https://github.com/mattijsf">@mattijsf</a>)
* <strong>SafeArea:</strong> Fix views with a filter having their content offset by the safe area insets (<a href="https://github.com/react/react-native/commit/fea820fa9bd08f966169ef519e0ee074f5953dbb">fea820fa9b</a> by <a href="https://github.com/intergalacticspacehighway">@intergalacticspacehighway</a>)
* <strong>StatusBar:</strong> <code>StatusBar</code> style and visibility work on iOS 27 for apps built with the iOS 27 SDK when <code>UIViewControllerBasedStatusBarAppearance</code> is <code>YES</code>. Custom root view controllers must return the <code>RCTStatusBarAppearance</code> values. (<a href="https://github.com/react/react-native/commit/bd08dafc98776a02e9b89c685d0475c48b6fd1b3">bd08dafc98</a> by <a href="https://github.com/alanjhughes">@alanjhughes</a>)
* <strong>SwiftPM:</strong> a project set up with skipped codegen no longer fails package resolution on <code>ReactAppHeaders</code> (<a href="https://github.com/react/react-native/commit/e3aa9a1e19734f58908be383103d5c4ce8bb9865">e3aa9a1e19</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>SwiftPM:</strong> the build-time sync now runs again when a watched path that did not exist at the last sync appears. (<a href="https://github.com/react/react-native/commit/c89f4120ac78f9808d2e15b9f46120636d59ded7">c89f4120ac</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>SwiftPM:</strong> keep line breaks in the scheme pre-action script so that the "Sync SPM Autolinking" pre-action runs. Run <code>npx react-native spm update</code> once to rewrite an existing scheme. (<a href="https://github.com/react/react-native/commit/b8df948fd4d22b3832c3e6319288232103cce700">b8df948fd4</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
