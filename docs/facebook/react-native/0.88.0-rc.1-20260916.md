# 0.88.0-rc.1

## release on 20260916
## description
## changes
Added

* <strong>EventTarget</strong>: Enable the imperative EventTarget API (<code>addEventListener</code>, <code>removeEventListener</code>, <code>dispatchEvent</code>) on native view refs in canary (<a href="https://github.com/react/react-native/commit/8480b86820b4535c9bec2967a0f16afed5292a0e">8480b86820</a> by <a href="https://github.com/rubennorte">@rubennorte</a>)

Changed

* <strong>Events</strong>: Enabled Web-based event dispatching refactor (<a href="https://github.com/react/react-native/commit/31d33ce91b127b434228c8d912810563afdede54">31d33ce91b</a> by <a href="https://github.com/rubennorte">@rubennorte</a>)
* <strong>Hermes</strong>: Bump Hermes to 260318099.0.3 (<a href="https://github.com/react/react-native/commit/79024f7c590446d3ef13bc1288faedb736957654">79024f7c59</a> by <a href="https://github.com/fabriziocucci">@fabriziocucci</a>)
* <strong>React</strong>: Sync React 19.3.0 into React Native (<a href="https://github.com/react/react-native/commit/b0b71421c1964e046ba2ad156669c7d32e4c538f">b0b71421c1</a> by <a href="https://github.com/rubennorte">@rubennorte</a>)

Fixed

iOS specific

* <strong>Codegen</strong>: No longer crawls <code>node_modules</code> or follows symlinks when discovering components (<a href="https://github.com/react/react-native/commit/39751d864dd340bbdaf59d7999ba4d787fba6dbc">39751d864d</a> by <a href="https://github.com/gabrieldonadel">@gabrieldonadel</a>)
* <strong>SwiftPM</strong>: Generated manifests derive their iOS platform floor from the app's <code>IPHONEOS_DEPLOYMENT_TARGET</code> instead of hardcoding iOS 15, so dependencies with a higher minimum (e.g. Expo, 16.4) can be autolinked (<a href="https://github.com/react/react-native/commit/92564f33fdaa8f0e9968712863e7e00f7073cdf7">92564f33fd</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>SwiftPM</strong>: Read the SwiftPM name from the podspec and store it in package.json when scaffolding (<a href="https://github.com/react/react-native/commit/1cfc5f29a00f7a2c5d7f842f4e99eae170e06422">1cfc5f29a0</a> by <a href="https://github.com/chrfalch">@chrfalch</a>)
* <strong>SwiftPM</strong>: Run generated build scripts under bash instead of /bin/sh, so they don't break on a host where /bin/sh isn't bash (<a href="https://github.com/react/react-native/commit/25f48bd72fd47799fe81689d58f4cbd1b9ddd21c">25f48bd72f</a> by <a href="https://github.com/lazerg">@lazerg</a>)
