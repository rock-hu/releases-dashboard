English

v1.17.0

Highlights

Use your ChatGPT subscription

Authorize Midscene through Sign in with ChatGPT (SIWC) to call GPT models using your ChatGPT subscription allowance. The video below demonstrates the browser extension's sign-in and authorization flow. See <a href="https://midscenejs.com/chatgpt-subscription" rel="nofollow">Use your ChatGPT subscription</a> for setup instructions.

Experimental Jev 1.14 support

Jev can handle planning, localization, and judgments, working with a general-purpose default model for tasks such as text input. See the <a href="https://midscenejs.com/model-api-setup#jev" rel="nofollow">Jev configuration guide</a> for setup instructions and limitations.

The following measurements come from a single run of each demo. A step means one model call; latency excludes page actions and waits. Costs are in USD, calculated at $0.042 per million Jev input tokens, with output tokens free of charge.

Fruit tile matching: Jev only

Jev handles clicks and localization to clear all fruit pairs until the remaining count reaches zero. <a href="https://lf3-static.bytednsdoc.com/obj/eden-cn/luljzkpt/ljhwZthlaukjlkulzlp/showcases/jev/fruits-tile-matching-report.html" rel="nofollow">View the execution report</a>.

* Model latency per call: <strong>0.887 seconds</strong> on average, <strong>0.774 seconds</strong> at P50.
* Input usage: <strong>6,761.4 tokens</strong> per call on average, <strong>101,421 tokens</strong> in total.
* Model cost: <strong>$0.000284</strong> per call on average, <strong>$0.00426</strong> in total.

Registration form: Jev + DeepSeek

Jev handles clicks, localization, gender dropdown selection, and completion checks. DeepSeek generates input values for the email, password, and username fields to complete the registration form together. <a href="https://lf3-static.bytednsdoc.com/obj/eden-cn/luljzkpt/ljhwZthlaukjlkulzlp/showcases/jev/register-form-report.html" rel="nofollow">View the execution report</a>.

The following measurements <strong>cover Jev only and exclude DeepSeek</strong>:

* Model latency per call: <strong>0.583 seconds</strong> on average, <strong>0.559 seconds</strong> at P50.
* Input usage: <strong>5,265.8 tokens</strong> per call on average, <strong>68,455 tokens</strong> in total.
* Model cost: <strong>$0.000221</strong> per call on average, <strong>$0.002875</strong> in total.

亮点

使用 ChatGPT 订阅额度

通过 Sign in with ChatGPT（SIWC）授权 Midscene，使用 ChatGPT 订阅额度调用 GPT 模型。下面的视频演示浏览器插件中的登录授权流程。接入方式详见<a href="https://midscenejs.com/zh/chatgpt-subscription" rel="nofollow">使用 ChatGPT 订阅</a>。

Jev 1.14 实验性支持

Jev 可用于任务规划、定位和判断，并与通用默认模型协同完成输入等任务。接入方式及限制详见 <a href="https://midscenejs.com/zh/model-api-setup#jev" rel="nofollow">Jev 配置指南</a>。

以下数据来自演示中的单次运行，“单步”指一次模型调用，耗时不包含页面操作和等待。费用单位为美元，按 Jev 输入 $0.042 / 百万 Token、输出免费计算。

水果连连看：纯 Jev

Jev 独立完成点击与定位，消除所有水果配对，直到剩余配对数为 0。<a href="https://lf3-static.bytednsdoc.com/obj/eden-cn/luljzkpt/ljhwZthlaukjlkulzlp/showcases/jev/fruits-tile-matching-report.html" rel="nofollow">查看运行报告</a>。

* 单步模型耗时：平均 <strong>0.887 秒</strong>，P50 <strong>0.774 秒</strong>。
* 输入消耗：平均每步 <strong>6,761.4 Token</strong>，总计 <strong>101,421 Token</strong>。
* 模型费用：平均每步 <strong>$0.000284</strong>，总计 <strong>$0.00426</strong>。

注册表单：Jev + DeepSeek

Jev 负责点击、定位、性别下拉框选择和完成判断；DeepSeek 生成邮箱、密码和用户名等输入内容，共同完成注册表单。<a href="https://lf3-static.bytednsdoc.com/obj/eden-cn/luljzkpt/ljhwZthlaukjlkulzlp/showcases/jev/register-form-report.html" rel="nofollow">查看运行报告</a>。

以下数据<strong>仅统计 Jev，不包含 DeepSeek</strong>：

* 单步模型耗时：平均 <strong>0.583 秒</strong>，P50 <strong>0.559 秒</strong>。
* 输入消耗：平均每步 <strong>5,265.8 Token</strong>，总计 <strong>68,455 Token</strong>。
* 模型费用：平均每步 <strong>$0.000221</strong>，总计 <strong>$0.002875</strong>。
