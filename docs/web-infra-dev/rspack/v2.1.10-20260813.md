Note

<strong>Removed noisy <code>import.meta</code> warnings</strong>

Rspack 2.1.9 introduced warnings for unknown <code>import.meta</code> properties. Because they proved overly noisy in real-world builds, Rspack 2.1.10 removes them to reduce unnecessary diagnostics for custom or runtime-specific extensions. See <a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5128966942" data-permission-text="Title is private" data-url="https://github.com/web-infra-dev/rspack/issues/15166" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15166/hovercard" href="https://github.com/web-infra-dev/rspack/pull/15166">#15166</a> for detail.
