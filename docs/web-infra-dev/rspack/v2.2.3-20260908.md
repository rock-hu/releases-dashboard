## changes
Highlights

CSS Import and Asset URL Externals

Rspack now supports <code>asset</code>, <code>asset-url</code>, and <code>css-import</code> external types, allowing CSS to reference stylesheets and assets hosted elsewhere. External <code>@import</code> statements preserve <code>layer</code>, <code>supports</code>, and media conditions, so conditional styles stay conditional in the emitted CSS. <a href="https://github.com/web-infra-dev/rspack/pull/15431" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15431/hovercard">#15431</a>, <a href="https://github.com/web-infra-dev/rspack/pull/15522" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15522/hovercard">#15522</a>.

More Flexible and Reliable Native Watching

With <code>experiments.nativeWatcher</code> enabled, <code>watchOptions.ignored</code> now accepts a function, making it easier to reuse existing ignore rules when switching to the native watcher. File event processing has also been improved to reduce event loss during large bursts of changes on Linux. <a href="https://github.com/web-infra-dev/rspack/pull/15254" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15254/hovercard">#15254</a>.

Lower Resolution Overhead for TypeScript Projects

Relative imports such as <code>./utils</code> and <code>../shared</code> no longer trigger unnecessary tsconfig loading or tracking of its project-reference tree. This reduces configuration reads and dependency tracking, especially in large TypeScript projects with many project references. <a href="https://github.com/web-infra-dev/rspack/pull/15492" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15492/hovercard">#15492</a>.
