What's Changed

Breaking Changes 🍭

The<code>filter.code</code> loader option (introduced in 2.3.0-beta.0) has been renamed to<code>codeFilter</code> . If you are upgrading from 2.3.0-beta.0, replace<code>filter: { code: ... }</code> with<code>codeFilter: ...</code> in your loader config. No action is needed if you never used<code>filter.code</code> .

    // 2.3.0-beta.0
    { loader: 'my-loader', filter: { code: 'customMacro(' } }

    // 2.3.0-beta.1
    { loader: 'my-loader', codeFilter: 'customMacro(' }
