Highlights

Corrected <code>compact-hashed</code> IDs naming

Rspack 2.2.0 introduced compact hashed module and chunk IDs under the mistakenly named <code>compat-hashed</code> option and <code>CompatHashedModuleIdsPlugin</code> / <code>CompatHashedChunkIdsPlugin</code> APIs. Rspack 2.2.1 corrects these names to <code>compact-hashed</code>, <code>CompactHashedModuleIdsPlugin</code>, and <code>CompactHashedChunkIdsPlugin</code>.

The names introduced in 2.2.0 remain available as deprecated compatibility aliases, but we recommend upgrading to Rspack 2.2.1 and using the corrected names:

    module.exports = {
      optimization: {
        moduleIds: 'compact-hashed',
        chunkIds: 'compact-hashed',
      },
    };
