# v2.2.4

## release on 20260914
## description
## changes
Highlights

CSS-only entry bundling

CSS-only entries using native CSS support now emit standalone stylesheets without an unnecessary JavaScript bundle. Standalone runtime chunks are also omitted when no JavaScript entry needs them, making it easier to build CSS assets directly. See <a href="https://github.com/web-infra-dev/rspack/pull/14879" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/14879/hovercard">#14879</a>.

Ignore magic comments in CSS

Native CSS support now recognizes <code>webpackIgnore</code> and its <code>rspackIgnore</code> alias for <code>@import</code>, <code>url()</code>, and <code>image-set()</code> dependencies. This lets you leave selected references for the browser to load instead of resolving and bundling them. See <a href="https://github.com/web-infra-dev/rspack/pull/15314" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15314/hovercard">#15314</a>.

Reliable persistent caching for child compilers

With <code>experiments.newCache</code>, parent and child compilers now coordinate access to shared persistent cache storage while keeping their entries separate. This prevents conflicting writes and cleanup from losing cached data, and allows both parent and child modules to be restored across compiler restarts. See <a href="https://github.com/web-infra-dev/rspack/pull/15616" data-hovercard-type="pull_request" data-hovercard-url="/web-infra-dev/rspack/pull/15616/hovercard">#15616</a>.
