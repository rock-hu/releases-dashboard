Highlights

Persistent cache storage options now align with webpack

Rspack now supports <code>cache.name</code> and <code>cache.storage.location</code>, aligning with webpack's persistent cache semantics. <code>cache.storage.directory</code> is now the base directory, while the final cache location defaults to <code>&lt;directory&gt;/&lt;cache.name&gt;</code>. Default cache paths remain unchanged.

If you previously used <code>storage.directory</code> as the exact cache path, migrate it to <code>storage.location</code>. Existing cache data is not migrated automatically.

    cache: {
      type: 'persistent',
      storage: {
        type: 'filesystem',
    -   directory: '/custom/cache',
    +   location: '/custom/cache',
      },
    }
