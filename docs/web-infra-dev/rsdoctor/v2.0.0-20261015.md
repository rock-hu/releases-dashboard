Highlights

Build analysis for agents

Agent CLI reads <code>rsdoctor-data.json</code> directly and returns structured data for step-by-step investigation. Rsdoctor 2.0 makes Agent CLI the recommended AI analysis workflow and adds compiler selection for multi-compiler reports.

Smaller and faster

Rsdoctor 2.0 reduces installation size from 25.5 MB to 11.1 MB and runtime dependencies from 83 to 18. In the published benchmarks, analysis time fell 57% compared with Rsdoctor 1.4. Watch-mode improvements reduced median HMR time by about 47%.

One report for every compiler

Rsdoctor automatically groups multi-compiler builds and detects child compilers. Switch between compiler results in the same report, or select a compiler in Agent CLI.

Improved bundle analysis

Tree Graph is smoother for large projects, while Treemap offers easier zooming and navigation. JavaScript asset filters and consistent size metrics help focus on the code that contributes to bundle size.

Breaking Changes

* <strong>Runtime requirements:</strong> Rsdoctor 2.0 requires Node.js <code>^20.19.0 || &gt;=22.12.0</code> and Rspack 2 or later. Rspack 1.x and webpack are no longer supported.
* <strong>Packages and imports:</strong> Replace <code>@rsdoctor/rspack-plugin</code> with <code>@rsdoctor/core</code>. Several standalone packages have been consolidated or removed, and Rsdoctor 2.0 packages are ESM-only.
* <strong>AI workflow:</strong> <code>@rsdoctor/mcp-server</code> and its MCP server workflow have been removed. Use Agent CLI with <code>rsdoctor-data.json</code>; it is not a drop-in MCP API replacement.
* <strong>Configuration:</strong> The top-level <code>mode</code>, <code>port</code>, and <code>brief</code> options, plus <code>output.compressData</code>, <code>supports.banner</code>, and <code>experiments.enableNativePlugin</code>, have been removed. Migrate to the corresponding 2.0 options.
* <strong>Deprecated APIs:</strong> Remaining deprecated APIs and options have been removed.

See the <a href="https://v2.rsdoctor.rs/guide/migration/migration-v2" rel="nofollow">Rsdoctor 2.0 migration guide</a> for replacement configuration and upgrade steps.
